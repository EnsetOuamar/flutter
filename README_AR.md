# Flutter Android App - Meter Data Collector

تطبيق جامع بيانات العدادات - تطبيق Flutter للهواتف الذكية

## الميزات

- ✅ قائمة بجميع العدادات المتاحة
- ✅ إدخال قراءات العدادات الجديدة على الهاتف
- ✅ حفظ القراءات محلياً (بدون انترنت)
- ✅ مزامنة البيانات مع تطبيق سطح المكتب عبر WiFi المحلي
- ✅ واجهة عربية كاملة
- ✅ عرض آخر قراءة مسجلة

## المتطلبات

### للتطوير:
- Flutter SDK (3.0+)
- Android Studio / VS Code
- Android NDK (للبناء)
- Dart 3.0+

### للتشغيل:
- هاتف ذكي يعمل بنظام Android 5.0+
- اتصال WiFi على نفس الشبكة مع جهاز الكمبيوتر

## التثبيت والبناء

### 1. تثبيت Flutter
```bash
# تحميل Flutter من:
https://flutter.dev/docs/get-started/install

# التحقق من التثبيت:
flutter doctor
```

### 2. استنساخ المشروع
```bash
cd flutter_app
flutter pub get
```

### 3. بناء التطبيق

#### للاختبار على محاكي:
```bash
# بدء محاكي Android
flutter emulators --launch <emulator_id>

# تشغيل التطبيق
flutter run
```

#### للبناء على جهاز فعلي:
```bash
# الجهاز يجب أن يكون متصلاً عبر USB
flutter devices  # تحقق من أن الجهاز معترف به

flutter run
```

#### بناء ملف APK:
```bash
flutter build apk

# أو ملف AAB (للمتجر):
flutter build appbundle
```

## الاستخدام

### خطوات الاستخدام:

1. **تشغيل تطبيق سطح المكتب (main_app.py)**
   ```bash
   python main_app.py
   ```
   - سيبدأ خادم المزامنة تلقائياً على المنفذ 5000
   - سترى رسالة: `[Sync Server] Starting on 192.168.x.x:5000`

2. **تثبيت التطبيق على الهاتف**
   - انسخ ملف APK إلى الهاتف أو استخدم `flutter run`

3. **إعداد الاتصال**
   - اضغط على أيقونة الإعدادات (⚙️)
   - أدخل عنوان IP للكمبيوتر (مثل: 192.168.1.100)
   - اضغط "اختبر الاتصال"
   - تأكد من أن الهاتف والكمبيوتر على نفس شبكة WiFi

4. **إدخال القراءات**
   - اختر عميلاً من القائمة
   - أدخل قراءة العداد الجديدة
   - اضغط "حفظ القراءة"
   - القراءة تُحفظ محلياً حتى المزامنة

5. **مزامنة البيانات**
   - اضغط على زر "مزامنة" (أو الرمز الأزرق في الأعلى)
   - ستُرسل جميع القراءات المعلقة إلى الكمبيوتر
   - بعد النجاح، ستُحذف القراءات المحفوظة محلياً

### المكتبات المستخدمة:

- **http**: للاتصالات بالخادم
- **shared_preferences**: لتخزين البيانات محلياً
- **intl**: لتنسيق التاريخ والوقت
- **connectivity_plus**: للتحقق من حالة الاتصال

## التدفق الديناميكي

### 1. الاتصال بالخادم:
```
الهاتف → HTTP GET /api/ping → الكمبيوتر
```

### 2. جلب قائمة العدادات:
```
الهاتف → HTTP GET /api/customers → الكمبيوتر
```

### 3. جلب آخر قراءة:
```
الهاتف → HTTP GET /api/meter/<meter_number>/last-reading → الكمبيوتر
```

### 4. مزامنة القراءات:
```
الهاتف → HTTP POST /api/sync/readings → الكمبيوتر
القراءات تُحفظ في قاعدة البيانات وتُحدّث الواجهة
```

## استكشاف الأخطاء

### مشكلة: "فشل الاتصال"
- ✓ تأكد من أن الكمبيوتر والهاتف على نفس شبكة WiFi
- ✓ تحقق من عنوان IP الصحيح (استخدم `ipconfig` على Windows)
- ✓ تأكد من أن تطبيق سطح المكتب يعمل
- ✓ تحقق من جدار الحماية (قد تحتاج لفتح المنفذ 5000)

### مشكلة: "لا توجد عدادات متاحة"
- ✓ تأكد من إضافة عملاء/عدادات في تطبيق سطح المكتب أولاً

### مشكلة: "قراءات معلقة لا تُمحى بعد المزامنة"
- ✓ تحقق من أن الرد من الخادم يحتوي على `"status": "success"`
- ✓ راجع سجل الخادم في تطبيق سطح المكتب

## ملاحظات الأمان

⚠️ **تنويه هام:**
- الاتصال الحالي **غير مشفّر** (HTTP وليس HTTPS)
